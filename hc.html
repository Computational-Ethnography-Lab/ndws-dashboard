Home Care

Data availability and access

Empirical analysis deferred

Public-use respondent files only, following the current project scope.

Home Care is not included in this public-use dashboard. An eligible HC public-use input has not been verified and integrated for this project; this is not a claim that no HC release exists.

No approved HC respondent file is included in this delivery. No HC estimates, sample sizes, weights, or models are generated.

Public questionnaires and catalogue links document survey instruments; they do not establish access to respondent data or support empirical estimates.

Empirical HC analysis is deferred under the current public-use-only scope. No AL or NH results are substituted for HC.

Evidence and limits

Restricted-use HC files were reported as available as of October 29, 2026. Current access status has not been rechecked for this page; consult the official release and access links below.

Before connecting HC data

  • An official respondent release and version, with access and redistribution terms approved for the project.
  • The matching codebook, questionnaire and value-label/format definitions.
  • Verified eligibility and skip rules, final weights, and released sampling-unit/design fields.
  • A reviewed HC loader and disclosure checks before displaying any estimates.
